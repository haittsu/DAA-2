# Assignment 2 — Algorithmic Analysis

Учебный проект по анализу алгоритмов на Java. Задание посвящено корректности и производительности динамического массива, связного списка и min-heap. Сейчас реализован динамический массив; остальные структуры, эксперименты и измеренные результаты ещё не добавлены.

## Структура

- `src/` — исходный код Java.
- `results/tables/` — таблицы с результатами будущих экспериментов.
- `results/plots/` — графики будущих экспериментов.

## Компиляция и запуск

Нужен установленный JDK с командами `javac` и `java` в `PATH`. Из корня репозитория:

```text
javac src/Main.java src/DynamicArray.java
java -cp src Main
```

Сторонние библиотеки не требуются. Пока `Main` только подтверждает запуск проекта; он не выполняет анализ и не создаёт результаты.

## Счётчики DynamicArray

`getElementAccessCount()` возвращает число чтений и записей ячеек внутреннего массива, включая копирование при расширении. `getComparisonCount()` считает сравнения значений в `contains(x)`. `getMovementCount()` считает переносы существующих элементов при сдвигах и расширении. `resetCounters()` обнуляет все три счётчика; время структура не измеряет.
