# Assignment 2 — Algorithmic Analysis

Учебный проект по анализу алгоритмов на Java. Задание посвящено корректности и производительности динамического массива, связного списка и min-heap. Сейчас реализованы динамический массив и односвязный список; min-heap, эксперименты и измеренные результаты ещё не добавлены.

## Структура

- `src/` — исходный код Java.
- `results/tables/` — таблицы с результатами будущих экспериментов.
- `results/plots/` — графики будущих экспериментов.

## Компиляция и запуск

Нужен установленный JDK с командами `javac` и `java` в `PATH`. Из корня репозитория:

```text
javac src/Main.java src/DynamicArray.java src/LinkedList.java
java -cp src Main
```

Сторонние библиотеки не требуются. Пока `Main` только подтверждает запуск проекта; он не выполняет анализ и не создаёт результаты.

## Счётчики структур данных

В `DynamicArray` метод `getElementAccessCount()` возвращает число чтений и записей ячеек внутреннего массива, включая копирование при расширении. `getComparisonCount()` считает сравнения значений в `contains(x)`. `getMovementCount()` считает переносы существующих элементов при сдвигах и расширении.

В `LinkedList` метод `getNodeVisitCount()` считает посещения существующих узлов при обходе или прямом обращении (включая доступ к хвосту при добавлении). `getComparisonCount()` считает сравнения значений в `contains(x)`. Обе структуры предоставляют `resetCounters()`; время внутри структур не измеряется.
