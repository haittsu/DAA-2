# Assignment 2 — Algorithmic Analysis

Учебный проект по анализу алгоритмов на Java. Задание посвящено корректности и производительности динамического массива, связного списка и min-heap. Сейчас подготовлен только каркас проекта: реализации структур данных, экспериментов и измеренных результатов ещё нет.

## Структура

- `src/` — исходный код Java.
- `results/tables/` — таблицы с результатами будущих экспериментов.
- `results/plots/` — графики будущих экспериментов.

## Компиляция и запуск

Нужен установленный JDK с командами `javac` и `java` в `PATH`. Из корня репозитория:

```text
javac src/Main.java
java -cp src Main
```

Сторонние библиотеки не требуются. Пока программа только подтверждает запуск каркаса; она не выполняет анализ и не создаёт результаты.
