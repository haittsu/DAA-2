# Assignment 2 — Algorithmic Analysis

Учебный проект по анализу алгоритмов на Java. Задание посвящено корректности и производительности динамического массива, связного списка и min-heap. Три структуры и четыре воспроизводимых workload реализованы; результаты создаются при запуске бенчмарка.

## Структура

- `src/` — исходный код Java.
- `results/tables/` — таблицы с результатами будущих экспериментов.
- `results/plots/` — графики будущих экспериментов.

## Компиляция и запуск

Нужен установленный JDK с командами `javac` и `java` в `PATH`. Из корня репозитория:

```text
javac src/Main.java src/DynamicArray.java src/LinkedList.java src/MinHeap.java src/Tests.java src/Benchmark.java
java -cp src Main
java -cp src Tests
java -cp src Benchmark
```

Сторонние библиотеки не требуются. Пока `Main` только подтверждает запуск проекта; он не выполняет анализ и не создаёт результаты.

`Tests` запускает проверки трёх структур без стороннего тестового фреймворка. Тесты сравнивают операции со стандартными коллекциями Java и проверяют свойство кучи после вставок и извлечений.

`Benchmark` использует `n = 100, 1000, 10000, 100000`, пять повторов и seed `42`. Он измеряет 10000 случайных `get`, 1000 `contains`, по 1000 вставок и удалений в начале и середине, а также `n` вставок и `n` извлечений из кучи. Подготовка входных данных, проверка результатов и печать выполняются вне измеряемых интервалов. Для удалений после каждого вызова исходное состояние восстанавливается вне таймера; суммируется только время `remove`, поэтому 1000 удалений возможны и при `n = 100`. Среднее суммарное время одного повтора и применимые счётчики сохраняются в `results/tables/benchmark.csv` после реального запуска; пустые ячейки означают неприменимый счётчик. Времена относятся к среде, в которой запущена программа.

## Счётчики структур данных

В `DynamicArray` метод `getElementAccessCount()` возвращает число чтений и записей ячеек внутреннего массива, включая копирование при расширении. `getComparisonCount()` считает сравнения значений в `contains(x)`. `getMovementCount()` считает переносы существующих элементов при сдвигах и расширении.

В `LinkedList` метод `getNodeVisitCount()` считает посещения существующих узлов при обходе или прямом обращении (включая доступ к хвосту при добавлении). `getComparisonCount()` считает сравнения значений в `contains(x)`.

В `MinHeap` метод `getComparisonCount()` считает сравнения значений при восстановлении свойства кучи после вставки и извлечения. Пустая куча вызывает `NoSuchElementException` при `peekMin()` и `extractMin()`.

Все структуры предоставляют `resetCounters()`; время внутри структур не измеряется.
